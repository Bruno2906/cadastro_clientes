# Sistema de Cadastro de Clientes

Projeto desenvolvido com HTML, CSS e JavaScript puro, com foco em manipulação de DOM e lógica de programação.

Funcionalidades
- Cadastro de clientes
- Listagem dinâmica
- Edição de dados (Update)
- Exclusão de registros
- Persistência com localStorage

Tecnologias
- HTML
- CSS
- JavaScript

Objetivo
Praticar conceitos de JavaScript, incluindo CRUD e manipulação de dados no front-end.
